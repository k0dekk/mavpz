# Платформа підготовки до НМТ

Веб-платформа для підготовки випускників. Користувач реєструється й обирає чотири предмети: три обов'язкові (математика, українська мова, історія) та один на вибір (англійська мова або фізика).

На сторінці кожного предмета є каталог питань, згрупованих за темами. Користувач розв'язує питання й бачить пояснення до них. Система зберігає кожну спробу, а неправильні відповіді потрапляють у розділ «Робота над помилками», де користувач додaає нотатки й позначає помилку опрацьованою.

## Що не входить

Оплата, роль адміністратора, питання на відповідності
